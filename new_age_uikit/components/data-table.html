Features & Architecture

⚡ Type-Aware Sorting
Automatically recognizes integers, decimals, currency values, dates, and strings. Sets aria-sort natively.
🔍 Fast Client Search
Indexes row contents into a cached memory array on load for sub-millisecond filtering across thousands of records.
📄 Slice Pagination
Toggles [hidden] attribute on out-of-slice rows without destroying DOM nodes, keeping framework virtual DOMs perfectly safe.
☑ Tri-State Row Selection
Header checkbox automatically computes indeterminate state when some rows are selected, with instant count updates.
