Components / Date Picker

Date Picker

A composed date picker component combining a trigger button with HTML Popover API and an interactive Calendar grid. Fully form-associated via ElementInternals.

Tier 2: Micro-Enhancer Popover API ElementInternals Zero Shadow DOM
Selected Value: None 
<!-- Native Form-Associated Date Picker -->
<div data-ui="field">
  <label data-ui="label">Appointment Date</label>
  <ui-date-picker name="appointment" placeholder="Pick a date..."></ui-date-picker>
</div>

<script type="module">
  const picker = document.querySelector('ui-date-picker');
  picker.addEventListener('change', (e) => {
    console.log('Selected date:', e.detail.value);
  });
</script>

Interactive Scenarios

Min / Max Boundary Limits
Constrained between Oct 5 and Oct 25, 2026.
Pre-selected Date
Initialized with an ISO date string and clear action.
Disabled State
Non-interactive state preventing popover toggle.
Form Submission
Submits standard FormData via ElementInternals.

Design & Composition

Native Popover API
Promoted directly to top-layer using popover="auto" with native outside click and Escape dismissal.
Composed Calendar
Reuses <ui-calendar> with full APG roving focus inside the floating overlay.
Form-Associated
Integrates with HTML standard FormData and form validation via ElementInternals.

API Reference

AttributeTypeDefaultDescription
valuestring—Selected date formatted as YYYY-MM-DD.
placeholderstring'Pick a date...'Trigger button label before date is chosen.
openbooleanfalseWhether the floating popover calendar is visible.
disabledbooleanfalseDisables opening the date picker.
minstring—Earliest selectable date boundary (YYYY-MM-DD).
maxstring—Latest selectable date boundary (YYYY-MM-DD).
namestring—Form field submission identifier.
