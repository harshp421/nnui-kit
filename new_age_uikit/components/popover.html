Popover

Top-layer floating panel anchored to a trigger element using native HTML Popover API and CSS Anchor Positioning.

Tier 1: Platform Primitives HTML Popover API Top Layer

Dimensions

Set the dimensions for the layer.

 
<ui-popover>
  <button data-part="trigger" data-ui="button" data-variant="outline">
    Open Dimensions
  </button>
  <div data-part="content" popover>
    <h4>Dimensions</h4>
    <p>Set the dimensions for the layer.</p>
  </div>
</ui-popover>
