Components / Dialog

Dialog (Modal)

Modal dialog built on HTML5 <dialog> and browser top-layer primitives, featuring backdrop blur, automatic focus trap, and Escape dismissal.

Tier 1 & 2: Platform Primitives < 0.8 KB Native <dialog>

Edit Profile

Make changes to your profile here. Click save when done.

 
<ui-dialog>
  <button data-part="trigger" data-ui="button">Open Modal Dialog</button>
  <dialog data-part="dialog">
    <div data-part="dialog-header">
      <h3 data-part="dialog-title">Edit Profile</h3>
      <p data-part="dialog-description">Make changes to your profile here.</p>
    </div>
    <div data-part="dialog-body">
      <div data-ui="field">
        <label data-ui="label">Name</label>
        <input data-ui="input" value="Harsh Parmar">
      </div>
    </div>
    <div data-part="dialog-footer">
      <button data-part="close" data-ui="button" data-variant="secondary">Cancel</button>
      <button data-part="close" data-ui="button">Save changes</button>
    </div>
  </dialog>
</ui-dialog>
