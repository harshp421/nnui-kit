API Reference

Attribute / Prop Type Default Description
persist "local" | "session" | "url" null Declarative state persistence. "local" persists current step index across reloads and tab closes.
sync "cross-tab" | boolean false Real-time synchronization across browser tabs via BroadcastChannel. Step updates synchronize instantly.
inspectAI() async () => Object - Returns machine-readable nnui.ai.v1 schema, live active step state, and framework snippets.
active-step number 1 Currently active step index (1-based index).
linear boolean false When enabled, prevents jumping to upcoming steps until current step is completed.
orientation "horizontal" | "vertical" "horizontal" Layout arrangement of the steplist and panels.
.next() () => void - Advances to the next sequential step index.
.prev() () => void - Returns to the previous step index.
.goToStep(n) (step: number) => void - Programmatically navigates to the specified step index.
change CustomEvent - Dispatched when active step changes: { step: number, previousStep: number }.
