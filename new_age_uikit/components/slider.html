Components / Slider

Slider

Accessible range slider component supporting mouse dragging, touch gestures, keyboard arrows (ArrowLeft/ArrowRight), step snapping, and ElementInternals form association.

Tier 2: Micro-Enhancer Form Associated Touch & Pointer Safe
Volume 50
Temperature (°C) 22
Brightness (Locked) 75 
<!-- Range Slider with Live Value Tracking -->
<ui-slider name="volume" min="0" max="100" step="1" value="50">
  <div data-part="track">
    <div data-part="range"></div>
  </div>
  <div data-part="thumb"></div>
</ui-slider>

<script>
  const slider = document.querySelector('ui-slider');
  slider.addEventListener('input', (e) => {
    console.log('Current value:', e.detail.value);
  });
</script>

API Reference

Attribute / Part Type Default Description
value number min Current value of the slider. Synchronizes with FormData.
min / max number 0 / 100 Minimum and maximum permitted range.
step number 1 Granular step snapping amount.
disabled boolean false Disables interaction and removes thumb from tab order.
onInput / onChange event — Dispatched while dragging (input) and upon release (change) with e.detail: { value }.
