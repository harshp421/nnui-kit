Switch

Smooth toggle switch powered by pure CSS transitions and semantic checkboxes without any client-side JavaScript.

Tier 0: Pure Semantic HTML Zero JS CSS Transitions

  <input type="checkbox" checked>
  <span>Airplane Mode</span>
</label>
