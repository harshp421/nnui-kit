Tags Input

Token Chip Editor

Accessible multi-token tag input with chip management, keyboard badge removal, and duplicate validation.

Interactive Demo

Press Enter or Comma to add
Press Backspace when empty to delete the previous tag.
Current Array: ["React", "TypeScript", "Tailwind"] 
<!-- Platform-Native Chip Tags Input -->
<ui-tags-input tags="React, TypeScript, Tailwind" max-tags="8" placeholder="Type tag..."></ui-tags-input>

API Reference

Attribute / Prop Type Default Description
tags string "" Comma-separated initial tags.
max-tags number Infinity Maximum allowable tags count.
placeholder string "Add tag..." Inner input field placeholder.
onChange CustomEvent - Dispatched on tag add or remove: { tags: string[], added?: string, removed?: string }.
