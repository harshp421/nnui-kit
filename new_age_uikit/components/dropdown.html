Dropdown Menu

Displays a contextual menu to the user — such as a list of actions or functions — triggered by a button. Built with APG roving tabindex and viewport auto-flip positioning.

Tier 2: Micro-Enhancer < 1.5 KB WAI-ARIA Menu Zero Shadow DOM

Anatomy

Pure Light-DOM markup contract with data-part attributes:

<ui-dropdown>

The root custom element micro-enhancer. Automatically manages focus, outside clicks, and positioning.

[data-part="trigger"]

The button element that toggles the dropdown menu. Receives aria-haspopup="menu" and aria-expanded.

[data-part="menu"]

The floating menu panel. Positioned below or above the trigger with viewport boundary clamping.

[data-part="item"]

Interactive menu item. Supports data-variant="destructive" and disabled.

API Reference

Attribute / Property Type Default Description
open boolean false Whether the dropdown menu is currently visible.
.open(focusIndex?) method - Programmatically opens the dropdown, focusing an optional item index.
.close() method - Programmatically closes the dropdown menu and restores focus.
.toggle() method - Toggles the open state of the dropdown menu.
select event - Dispatched when an item is selected. Detail: { value, label, item }.
