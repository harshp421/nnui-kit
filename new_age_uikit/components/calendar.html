Components / Calendar

Calendar

A date field component that allows users to enter and edit date values using an accessible grid, month navigation buttons, and APG roving keyboard focus.

Tier 2: Micro-Enhancer < 2 KB WAI-ARIA Grid ElementInternals
Selected Date: 2026-10-03 
<!-- Standalone Form-Associated Calendar -->
<ui-calendar value="2026-10-03" name="appointment_date"></ui-calendar>

<script type="module">
  const cal = document.querySelector('ui-calendar');
  cal.addEventListener('change', (e) => {
    console.log('Selected date:', e.detail.value);
  });
</script>

Examples & Boundaries

Date Boundary Constraints
Selectable only between October 5 and October 25, 2026. Out-of-range dates are disabled.
Native Form Association
Standard FormData integration without any hidden input elements.

Keyboard Navigation (WAI-ARIA APG)

← / →
Move focus to previous or next day
↑ / ↓
Move focus up or down by one week
PageUp / PageDn
Switch to previous or next month
Enter / Space
Select the focused date
