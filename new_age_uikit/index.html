Inverting the Universal Component Stack

Why settle for Shadow DOM accessibility traps or maintaining 5 separate framework adapter packages?

Tier 0: Pure Semantic HTML

Zero-JS first paint. Every control renders standard semantic HTML that search engine crawlers index immediately. Scoped cascade layers (@layer ui.tokens, ui.reset, ui.base) guarantee consumer utility classes override without !important.

Tier 1: Platform Primitives

Replaces 50KB+ third-party layout engines (Floating UI / Popper) with the browser's native C++ layout engine: CSS Anchor Positioning, HTML Popover API, and native <dialog> top-layer rendering.

Tier 2: Micro-Enhancers (< 4KB)

Enforces the strict "Mutate Attributes, Never Nodes" invariant. Coordinates state via attributes so React 19, Vue 3, and Svelte 5 virtual DOM reconcilers never suffer hydration mismatches.
