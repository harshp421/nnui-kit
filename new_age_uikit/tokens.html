Design System / Tokens / Architecture

Design Tokens & System Architecture

Token taxonomy conforming to the W3C Design Tokens Community Group (DTCG) specification. Bridging Figma Token Studio and CSS custom properties with zero drift.

Tier 1

Reference Tokens

Raw scale definitions: Zinc 50-950, Spacing 1-24, Easing cubic-beziers. Unopinionated mathematical constants.

Tier 2

System / Semantic

Role-based bindings: --ui-bg-surface, --ui-text-primary, --ui-border-focus. Automatically invert in dark mode.

Tier 3

Component Tokens

Component-scoped variables: --ui-button-height, --ui-calendar-cell-size. Fully customizable without breaking cascade layers.
