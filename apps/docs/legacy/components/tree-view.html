Tree View

Hierarchy

Accessible hierarchical folder and node explorer with 4-way keyboard navigation (Up, Down, Left, Right) in Light-DOM.

<!-- Platform-Native Hierarchical Tree View -->
<ui-tree-view selection-mode="single">
  <ul data-part="tree">
    <li data-part="item" data-value="src" aria-expanded="true">
      <span data-part="label">📁 src</span>
      <ul data-part="group">
        <li data-part="item" data-value="app.js"><span data-part="label">📄 app.js</span></li>
      </ul>
    </li>
    <li data-part="item" data-value="package.json"><span data-part="label">📦 package.json</span></li>
  </ul>
</ui-tree-view>

API Reference

Attribute / Prop Type Default Description
selection-mode "single" | "multiple" "single" Selection behavior mode.
onSelect CustomEvent - Dispatched on node selection: { item, value, selected }.
onToggle CustomEvent - Dispatched on expand/collapse: { item, expanded }.
