Virtualized Data Grid

Enterprise Virtualization

API Reference

Method / Prop Type Default Description
persist "url" | "session" | "local" null Declarative state persistence. "url" synchronizes search and sorting with browser URL params.
sync "cross-tab" | boolean false Real-time synchronization across browser tabs via BroadcastChannel.
inspectAI() async () => Object - Returns machine-readable nnui.ai.v1 schema, live state, and React/Vue/Svelte code snippets.
setColumns(cols) Array<Column> [] Sets column schema with keys, labels, widths, and sort flags.
setRows(rows) Array<Object> [] Populates the grid with any size dataset (up to 100,000+ records).
appendRows(newRows, options) Array<Object> - Streams incoming rows into the grid without re-sorting the full dataset.
setSearch(query) string "" Performs fast multi-column full-text search filtering. Automatically persisted if persist is enabled.
exportCsv(filename) string "export.csv" Exports filtered or selected records into a downloadable CSV file.
startStreaming(ms) number 400ms Starts live simulated real-time streaming of new data rows.
