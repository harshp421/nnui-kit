<ui-sheet side="right">
  <button data-part="trigger" data-ui="button">Open Sheet</button>
  <dialog data-part="dialog">
    <div data-part="sheet-content">
      <div data-part="sheet-header">
        <h3 data-part="sheet-title">Edit Configuration</h3>
        <p data-part="sheet-description">Configure cluster instances.</p>
      </div>
      <div data-part="sheet-body">
        <!-- Form fields -->
      </div>
      <div data-part="sheet-footer">
        <button data-part="close" data-ui="button" data-variant="secondary">Cancel</button>
        <button data-part="close" data-ui="button">Save Changes</button>
      </div>
    </div>
  </dialog>
</ui-sheet>

API Reference

Attribute / Part Type Default Description
side "right" | "left" | "top" | "bottom" "right" Edge from which the drawer slides into view.
open boolean false Controls sheet visibility.
showModal() / close() method — Opens with top-layer focus trap or closes with slide-out animation.
[data-part="trigger"] element Optional Clicking automatically invokes showModal().
[data-part="close"] element Optional Clicking automatically triggers dismiss transition.
