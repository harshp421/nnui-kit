Date Range Picker

Dual Calendar

Accessible date range selector featuring dual-month calendar navigation, hover range highlighting, and instant preset shortcuts.

Interactive Demo

Click to open dual-calendar popover
Cross-Tab Sync: sync="cross-tab" + persist="local"
Selected Range: None 
<!-- Platform-Native Dual Calendar Date Range Picker with Cross-Tab Sync -->
<ui-date-range-picker placeholder="Select dates..." persist="local" sync="cross-tab"></ui-date-range-picker>

API Reference

Attribute / Prop Type Default Description
persist "local" | "session" | "url" null Declarative state persistence for selected date range.
sync "cross-tab" | boolean false Real-time synchronization across browser tabs via BroadcastChannel.
inspectAI() async () => Object - Returns machine-readable nnui.ai.v1 schema, live range state, and framework snippets.
start-date string null Initial start date in YYYY-MM-DD format.
end-date string null Initial end date in YYYY-MM-DD format.
placeholder string "Select date range..." Trigger input placeholder text.
open boolean false Reflects the popover calendar open state.
onChange CustomEvent - Dispatched when range is confirmed: { start, end, range }.
